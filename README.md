# HR Attrition & Employee Analysis 📊

An end-to-end HR Analytics project built using Excel, MySQL, and Power BI to analyze employee attrition and workforce trends.

The project analyzes 3,000 employee records and covers attrition rate, active employees, department-wise attrition, job roles, tenure, gender, satisfaction, overtime, work-life balance, employee ratings, engagement, training, and termination trends.

### 🛠️ Tech Stack & Workflow:
* **Excel** — Data cleaning, preparation & exploratory analysis
* **MySQL** — Data validation, SQL analysis, JOINs, CTEs & Window Functions
* **Power BI** — Data modeling, DAX measures, KPIs & interactive dashboard

### 📌 Key Results:
* **Total Employees:** 3,000
* **Employees Left:** 1,533
* **Attrition Rate:** 51.10%
* **Active Employees:** 1,467
* **Average Satisfaction:** 3.02 / 5
* **Average Tenure:** 3.39 Years

**📌 Dataset:** Kaggle

**🎯 Objective:** Transform raw HR data into meaningful workforce insights that can support better employee retention and HR decision-making.

**Skills:** Excel | SQL | MySQL | Power BI | DAX | Data Analysis | HR Analytics | Data Visualization
